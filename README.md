## The tip

> Tip: you are the only one in this loop with a heartbeat. The tests are red, the agent is confident, and the error message is the only honest one here.

One line, 150 characters. A loading-screen tip for stressed developers and
AI coding agents, written to land mid-build.

## How it works

`main.py` (standard library only) writes the tip to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

```sh
python3 main.py
cat /output/entry.txt
```
